## 3) `.cursorrules` 구조 (완성본)

| 섹션 | 핵심 내용 |
|------|-----------|
| `project` | Magic_Square_XX, SSOT(Report/01·02), 입출력·M=34, DT/UT/IT 트랙 |
| `code_style` | Python 3.10+, PEP8, type hints, Google docstring, line 88, print 금지 |
| `architecture` | ECB boundary/control/entity, `boundary -> control -> entity`, data는 infra |
| `tdd_rules` | Dual-Track; red/green/refactor 각 `description`·`rules`·`must_not` |
| `testing` | pytest, AAA, coverage 80%+, fixture scope, `test_` 접두사 |
| `forbidden` | print, 하드코딩 상수, bare except, RED 우회, 테스트 약화, import 위반 등 |
| `file_structure` | `src/magicsquare/{boundary,control,entity,data}`, `tests/{entity,boundary,integration,fixtures}` |
| `ai_behavior` | 코드 전·중·후 절차, TDD 위반 시 경고 블록 출력 |

**YAML 검증:** PyYAML `safe_load` 통과 (8개 최상위 키).

**적용 한계:** Cursor는 `.cursorrules`를 실행 가능한 상태기가 아닌 **컨텍스트 텍스트**로 주입한다. `proceed_when` 등은 모델 준수에 의존.

## 5) 초기 구현 — User 엔티티 (entity 레이어)

### 5.1 목적

Report/02 Data 레이어 `id` 규칙(`^[a-zA-Z0-9_-]{1,32}$`)과 연계할 **플레이어 식별** 도메인 모델.  
ECB **entity**만 구현; boundary/control/data 미구현.

### 5.2 도메인 계약

| 항목 | 규칙 |
|------|------|
| `user_id` | 1~32자, `[a-zA-Z0-9_-]` |
| `display_name` | strip 후 1~64자 |
| 불변성 | `@dataclass(frozen=True, slots=True)` |
| 변경 | `rename()` → 새 `User` 인스턴스 |
| 실패 | `UserValidationError(code, message)` |

### 5.3 파일

| 경로 | 설명 |
|------|------|
| `src/magicsquare/entity/user.py` | `User` 엔티티 |
| `src/magicsquare/entity/exceptions.py` | `UserValidationError` |
| `src/magicsquare/entity/__init__.py` | export |
| `tests/entity/test_entity_user.py` | DT-USER-01 ~ 09 |
| `pyproject.toml` | 패키지·pytest `pythonpath=src` |
