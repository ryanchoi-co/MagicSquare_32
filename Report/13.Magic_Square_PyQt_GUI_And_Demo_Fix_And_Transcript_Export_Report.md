## Demo BV 정합 수정 (이슈)

### 문제

- 버튼 라벨 `3×4`만으로는 **3행×4열** vs **4행×3열** 혼동 가능
- 고정 4×4 위젯에서 데모 클릭 시 **화면은 4×4**, 검증은 **3행 리스트**만 사용 → UI·로직 불일치
- Submit 시 4행 빈 칸이 0으로 읽혀 **잘못된 4×4**로 통과할 위험

### 해결

| 항목 | 내용 |
|------|------|
| 라벨 | `3 rows × 4 cols` / `4 rows × 3 cols` (test_plan BV-04a/b) |
| 시각 | 초과 행/열 비활성(회색, `—`) |
| 제출 | `_grid_override`로 `demo_grids.py` 정본 격자 제출 |
| 메시지 | `BV-04a (3 rows × 4 cols) → Grid must be 4x4.` |

데모 격자 SSOT: `src/magicsquare/boundary/screen/demo_grids.py` (conftest `GRID_3X4` / `GRID_4X3`와 동일 값).
