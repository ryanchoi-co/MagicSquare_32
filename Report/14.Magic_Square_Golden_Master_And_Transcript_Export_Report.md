## Import 이슈 및 수정

### 문제

```text
pytest tests\golden_master\test_golden_master_magic_square.py -v
ModuleNotFoundError: No module named 'tests'
```

`pyproject.toml`의 `pythonpath = ["src"]`만 설정되어 `from tests.golden_master...` 절대 import 실패.

### 해결

`tests/golden_master/` 내부를 boundary 테스트와 동일하게 **상대 import** (`from .approve import ...`)로 통일.
