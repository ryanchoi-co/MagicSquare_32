## 4) Level 3 User Stories (Summary)

### Story 1 (Boundary): Input Validation
- Validate 4x4 shape, exact two blanks, value range, non-zero uniqueness
- On validation failure: Domain solver must not be called

### Story 2 (Domain): Blank Coordinate Discovery
- Detect exactly two blank coordinates in row-major order

### Story 3 (Domain): Missing Number Discovery
- Find exactly two missing numbers from 1..16 excluding 0
- Return numbers in ascending order

### Story 4 (Domain): Magic Square Validation
- Validate row/column/diagonal sums against 34
- Return true only when all invariant conditions are satisfied

### Story 5 (Domain): Two-combination Solver
- Try small-first assignment first, then reverse if needed
- Return `int[6]` as `[r1,c1,n1,r2,c2,n2]` with 1-index coordinates
- If both fail, return defined failure

## 5) Level 4 Technical Scenarios (Defined)

Each scenario includes:
